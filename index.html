ООО Продвижение

Backend Разработчик

Фев 2026 — Июн 2026

Разработка backend для спортивного трекера для футбола: обмен данными с устройством и клиентскими компонентами, REST API и бизнес-логика. Ответственность за разработку, тестирование, документацию, поставку и сопровождение сервисов.

Ключевые достижения

  • Спроектировал и реализовал 4 backend-сервиса на Go и Python, включающих 43 REST API-эндпоинта.
  • Интегрировал backend с трекером и клиентскими компонентами, устранял ошибки обмена данными и стабилизировал работу API.
  • Автоматизировал развёртывание сервисов в Kubernetes и настройку окружений.
  • Настроил CI/CD в GitHub Actions и управление секретами через Vault, обеспечив выполнение пайплайна.
  • Внедрил сбор метрик и логов через Prometheus, Grafana и Loki для мониторинга сервисов и диагностики сбоев.

Стек Go, Python, FastAPI, REST API, Kubernetes, GitHub Actions, Vault, Prometheus, Grafana, Loki

РТСофт

C++ Backend Разработчик

Авг 2024 — Ноя 2025

Разрабатывал C/C++ backend-компоненты для embedded runtime промышленных устройств, где были критичны отказоустойчивость, диагностика состояния узлов и воспроизводимая сборка. Отвечал за backend-интерфейс репликации и сервисы мониторинга. Разработка компонентов среды исполнения промышленных устройств на C/C++. Основные задачи — разработка системы мониторинга, модификация системы исполнения и настройка CI пайплайна.

Ключевые достижения

  • Спроектировал и внедрил отказоустойчивый C/C++ backend-интерфейс репликации для узлов embedded runtime.
  • Реализовал monitoring/control-сервисы для централизованного контроля узлов и системных переменных.
  • Стандартизировал сборку backend-компонентов через CMake и Docker.
  • Настроил GitLab CI пайплайн для build, test и release flow.
  • Внедрил structured diagnostics, status checks и единый API-слой для контроля компонентов.

Стек C, C++, CMake, Docker, GitLab CI, REST API, Embedded, Monitoring
