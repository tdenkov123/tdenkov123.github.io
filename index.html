Backend разработчик

Фев 2026 — Июн 2026

Разрабатывал backend-сервисы на Go и Python для спортивного трекера для футбола: стабильный API-обмен, воспроизводимая поставка и наблюдаемость. Отвечал за REST API, бизнес-логику, тестирование, документацию, CI/CD, Kubernetes-deployment, работу с секретами и production monitoring.

  • 4 / 28сервиса и REST endpoints end to end
  • 5д → 2дподключение новой интеграции
  • 4ч → 35мразвёртывание окружения
  • 90 → 25мMTTR после observability

Ключевые достижения

  • Спроектировал и реализовал 4 backend-сервиса на Go и Python, 28 REST API endpoints end to end; унификация API contracts, validation и тестирования сократила срок подключения новой интеграции с 5 рабочих дней до 2.
  • Подготовил Kubernetes-deployment для backend-сервисов с конфигурацией окружений и production safeguards; сократил развёртывание нового окружения с 4 часов до 35 минут и исключил 8 ручных шагов.
  • Настроил GitHub Actions и Vault-based secret management; сократил release pipeline с 24 до 11 минут и количество ручных операций с секретами с 6 до 1.
  • Внедрил observability через Prometheus, Grafana и Loki для метрик, логов и диагностики; сократил MTTR с 90 до 25 минут.
  • Интегрировал трекер и клиентские компоненты и стабилизировал API; снизил количество интеграционных ошибок с 10 до 4 на release cycle и время ручной диагностики с 60 до 20 минут.

Стек Go, Python, REST API, Kubernetes, GitHub Actions, Vault, Prometheus, Grafana, Loki, CI/CD, Monitoring, Deployment Automation, Secret Management

C++ Backend разработчик

Авг 2024 — Ноя 2025

Разрабатывал C/C++ backend-компоненты для embedded runtime промышленных устройств, где были критичны отказоустойчивость, диагностика состояния узлов и воспроизводимая сборка. Отвечал за backend-интерфейс репликации, monitoring/control-сервисы, Docker packaging и GitLab CI release flow.

  • 32 узлаfailover за 5 секунд
  • 50 → 8мполная диагностика контура
  • 42 → 14мвремя release-сборки
  • −40%повторных инцидентов

Ключевые достижения

  • Спроектировал и внедрил отказоустойчивый C/C++ backend-интерфейс репликации для 32 узлов embedded runtime; обеспечил автоматическое переключение на резервный узел за 5 секунд и восстановление без ручного перезапуска в 19 из 20 тестовых сценариев.
  • Реализовал monitoring/control-сервисы для централизованного контроля 40 узлов и 120 системных переменных; сократил полную диагностику состояния с 50 до 8 минут.
  • Стандартизировал сборку backend-компонентов через CMake и Docker packaging; сократил время release-сборки с 42 до 14 минут и устранил расхождения между 3 окружениями.
  • Настроил GitLab CI pipeline для build, test и release flow; сократил число ручных операций с 11 до 3 и подготовку поставки с 6 часов до 90 минут.
  • Внедрил structured diagnostics, status checks и единый API-слой для контроля компонентов; сократил обнаружение проблем с 30 до 7 минут и число повторных инцидентов на 40%.

Стек C, C++, CMake, Docker, GitLab CI, REST API, Embedded Runtime, Fault-Tolerant Interface, Monitoring, Control Services, Release Flow
